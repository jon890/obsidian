- Agentic Search에서의 BM25
	- https://www.youtube.com/watch?v=yNPS1Z64wQM
	- BM25 = Best Match 25
	- 사람은 보통 2~3단어 검색
	- GPT-5는 10단어를 검색
		- 다양한 검색 연산자도 자유롭게 설정
	- BM25가 agent search에서 강력한 이유
		- EXACT
		- CHEAP
		- EXPLAIN
	- BM25 + grep Is All You Need
		- BM25로 1차적 검색
			- Agent를 위한 검색 페이지와 같은 용도로 활용
		- 찾아낸 검색결과를 grep과 같은 파일 시스템으로 접근할 수 있게해주면 Agent가 자율적으로 탐색하여 점진적 정보 탐색이 가능함
		- 동적 워크스페이스 확장을 통한 코퍼스 직접 상호작용의 확장
